How To Enable or Disable Automatic Microsoft Edge Restart to Update

By Bashkarla / How To, Windows 11

Learn how to enable or disable Microsoft Edge to automatically restart when it’s idle to update itself.

Microsoft Edge, like other web browsers, can automatically update itself in the background as needed. Generally, the browser waits till you close it to fully complete the update process. It even shows a small notification when you are required to restart the browser to complete the update. However, to make things simpler and ensure updates are applied fully, Microsoft introduced a new feature that automatically restarts the Edge browser to update when it’s idle. By default, this feature is disabled. If you want, you can enable the ‘Restart to update on idle’ feature to make sure your browser is always up to date. In this quick and easy guide, I will show you the steps to turn ON or off the automatic restart of Edge to update when idle in Windows 11. Let’s get started.

Enable or Disable Automatic Microsoft Edge Restart to Update

You can turn on or off the automatic restart feature to update the browser via the Edge settings. Here’s how to do it in simple steps.

To start off, open the Microsoft Edge browser. To do that, either click the Edge icon on the taskbar or open the Start menu, search for “Microsoft Edge”, and click the “Open” option in the right panel of the Start menu.

After the browser opens, click the “Settings and more” icon (three horizontal dots) and then select the “Settings” option.

In the Settings tab, go to the “About Microsoft Edge” tab on the left sidebar. On the right panel, configure the “Restart to update on idle” option as follows.

  • Turn ON the toggle: Enables Edge to automatically restart when idle to apply updates.
  • Turn OFF the toggle: Stops Edge from automatically restarting to apply updates (default option).

Important note: Edge considers the browser to be in an idle state if you are not using it for more than 20 minutes.
